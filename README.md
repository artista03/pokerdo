# ポーカー道 — スマホ復習版

今井陽介がGTO Wizardの実戦練習で**実際に間違えた633スポット**を、スマホからランダムに解き直すための静的サイト。

## 使い方

1. スマホで GitHub Pages のURLを開く（ホーム画面に追加すればアプリのように使える）
2. 問題に答える
3. **間違えたら質問欄が出る。**「なぜ自分にはそう見えたか」をそのまま書く
4. 質問と成績は `sync.json` としてこのリポジトリに書き戻される
5. コーチ（Claude）がターミナルから `sync.json` を読み、回答を書いてこのサイトに戻す

## 出題の仕組み

完全ランダムだが、**一度間違えた問題は「克服」するまでプールに残り続ける**。
克服＝2連続で正解すること。ヘッダーの「復習待ち」がその残数。

## 同期（GitHub トークン）

設定画面でトークンを1回貼るだけ。以後は自動で同期する。
トークンは端末の localStorage にのみ保存され、このリポジトリには入らない。

**推奨：fine-grained personal access token**
- Repository access → **このリポジトリだけ**
- Permissions → Contents: **Read and write**

こうしておけば、万一漏れても他のリポジトリには手が届かない。

トークンを設定しなくても練習自体は動く（成績はその端末だけに残る）。

## ファイル

| | |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `data.json` | 633問＋解説＋コーチの回答。**生成物**（手で編集するな） |
| `sync.json` | 質問と成績。アプリが書き、コーチが読む |

## データの正はどこか

このリポジトリではない。**正データはローカルの `~/ポーカー道/`** にある。

```
game/explanations.json   解説の正データ
game/answers.json        コーチの回答の正データ
        ↓  python3 build_game.py
        ↓  python3 build_mobile.py
mobile/data.json         ← 生成物。これをpushする
```

解説を直したい時は `explanations.json` を直してから上の2本を回す。
